# PLP Python Week 4 Assignment: Functions

## File Descriptions
- `welcome.py`: Contains a reusable `welcome()` function that generates personalized greetings for PLP students, eliminating repetitive code.
- `toolbox.py`: A collection of three utility functions (`double`, `is_pass`, and `greet`) demonstrating arithmetic operations, Boolean condition returns, and optional default arguments.

## Reflection
The `greet` function was the most complex to write because it involved handling an optional default parameter (`greeting="Hello"`). Remembering to structure the parameters so default arguments follow non-default ones and formatting the string with proper punctuation took extra attention.
